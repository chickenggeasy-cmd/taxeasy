# ภาษีง่ายๆ (TaxEasy)

แอปคำนวณภาษีเงินได้บุคคลธรรมดาของไทย ใช้บนมือถือเป็นหลัก และเปิดบนคอมได้ด้วย กรอกรายได้กับค่าลดหย่อน แล้วรู้ทันทีว่าได้เงินคืนหรือต้องจ่ายเพิ่มเท่าไร

**คำนวณภาษี**
- รายได้ครบ 40(1)–40(8) รวมเงินปันผลและดอกเบี้ย 40(4) หักค่าใช้จ่ายตามประเภทให้เอง
- ค่าลดหย่อนทุกหมวด ตรวจเพดานให้อัตโนมัติ เช่น กลุ่มเกษียณรวมไม่เกิน 500,000 บาท และประกันชีวิตรวมกับประกันสุขภาพไม่เกิน 100,000 บาท
- คิดภาษีทั้งวิธีขั้นบันไดและวิธี 0.5% แล้วใช้ยอดที่สูงกว่าตามกฎหมาย
- กรอกเงินเดือนรายเดือนได้ รองรับคู่สมรส เงินได้จากต่างประเทศ และภาษีครึ่งปี ภ.ง.ด.94

**วางแผนและยื่นภาษี**
- **มีงบเท่านี้ ลงอะไรดี:** ใส่งบที่มี แอปจัดให้ว่าควรลง ThaiESG / RMF / ประกันเท่าไร และบอกว่าใช้แค่เท่าไรก็พอ
- **ลองดูว่า "ถ้า…":** เลื่อนแถบเงินเดือน งานเสริม ค่าลดหย่อน แล้วดูภาษีเปลี่ยนทันที พร้อมกราฟขั้นบันไดภาษี
- ขั้นตอนยื่นผ่าน e-Filing รายการเอกสาร เพิ่มวันยื่นลงปฏิทิน และแชร์ผลเป็นรูป

**อื่น ๆ**
- **น้องภาษี (AI ผู้ช่วย)** ตอบคำถามจากตัวเลขของผู้ใช้ และ **สแกนใบ 50 ทวิ** ให้กรอกเอง (ต้องเปิดใช้ AI)
- **อัปเดตกฎภาษีได้เอง:** แอดมินแก้กฎในหลังบ้านแล้วกดเผยแพร่ แอปของผู้ใช้ดึงกฎใหม่ไปใช้ ไม่ต้องแก้โค้ด
- ตลาดหุ้นโลก ธีมมืด โหมดตาบอดสี ข้อมูลตัวอย่าง 4 แบบสำหรับเดโม
- ข้อมูลรายได้ของผู้ใช้เก็บไว้ในเครื่องผู้ใช้ ไม่ส่งขึ้นเซิร์ฟเวอร์ มีหน้าแจ้งปัญหาและนโยบายความเป็นส่วนตัว

## ติดตั้งบน XAMPP

### สิ่งที่ต้องมี

- **XAMPP for Windows รุ่น 8.3** (PHP 8.3) จาก <https://www.apachefriends.org/download.html>
  - แอปและหลังบ้านใช้ได้กับ PHP 8.0 ขึ้นไป แต่ **AI ผู้ช่วยและสแกน 50 ทวิ ต้องใช้ PHP 8.1 ขึ้นไป** แอปทดสอบกับ PHP 8.3 แล้ว
  - ตอนติดตั้งเอาติ๊ก Tomcat ออกได้ เพราะไม่ได้ใช้
- **Git for Windows** จาก <https://git-scm.com/download/win>
- **VS Code** (ใช้ Terminal พิมพ์คำสั่ง)

ในคู่มือนี้ใช้โฟลเดอร์ XAMPP ที่ `C:\xampp` ถ้าติดตั้งไว้ที่อื่น เช่น `C:\xampp83` ให้เปลี่ยนตามนั้นทุกจุด

### ตั้งพอร์ต Apache เป็น 8080

ถ้าพอร์ต 80 ชนกับโปรแกรมอื่น (Apache ไม่ยอม Start):

1. XAMPP Control Panel → แถว Apache กด **Config** → **Apache (httpd.conf)**
2. แก้ `Listen 80` เป็น `Listen 8080`
3. แก้ `ServerName localhost:80` เป็น `ServerName localhost:8080`
4. บันทึก แล้วกด Start ที่ Apache ใหม่

### ติดตั้งแอปครั้งแรก

1. เปิด Terminal ใน VS Code (Ctrl+\`) แล้วพิมพ์:
   ```
   cd C:\xampp\htdocs\project_data
   git clone -b xampp https://github.com/chickenggeasy-cmd/taxeasy.git Texeasy
   ```
   (ถ้ายังไม่มีโฟลเดอร์ `project_data` ให้สร้างก่อน)
2. Start **Apache** และ **MySQL**
3. **สร้างฐานข้อมูล:** เปิด phpMyAdmin → แท็บ **Import**
   - นำเข้า `Texeasy\database\schema.sql` ก่อน (สร้างฐานข้อมูลชื่อ `taxeasy` ให้)
   - คลิก `taxeasy` ทางซ้าย แล้วนำเข้า `Texeasy\database\seed.sql` (กฎภาษีปี 2568 และ 2569)
4. **สร้างบัญชีแอดมิน:** เปิดลิงก์หลังบ้าน แล้วตั้งชื่อผู้ใช้และรหัสผ่าน (ทำได้ตอนที่ยังไม่มีบัญชีเท่านั้น)
5. **เปิดแอป** จากลิงก์ด้านบน

ถ้า MySQL ตั้งรหัสผ่าน root ไว้ ให้ใส่ใน `server\config.local.php` (ดูวิธีสร้างไฟล์ในหัวข้อ AI) เช่น `$c['db']['pass'] = 'รหัสผ่าน';`

### อัปเดตเป็นเวอร์ชันล่าสุด

ทุกครั้งที่แก้โค้ดในสาขา `main` GitHub จะทดสอบและ build แอปให้อัตโนมัติ แล้วเก็บไว้ในสาขา `xampp` อัปเดตในเครื่องด้วย:

```
cd C:\xampp\htdocs\project_data\Texeasy
git pull
```

จากนั้นกด **Ctrl+Shift+R** ในเบราว์เซอร์เพื่อโหลดแอปใหม่

- ไฟล์ `server\config.local.php` ที่สร้างเอง git จะไม่แตะต้อง
- **ห้ามแก้ไฟล์ในโฟลเดอร์นี้เอง** ถ้าเผลอแก้แล้ว `git pull` ไม่ผ่าน ให้พิมพ์ `git checkout -- .` (คืนไฟล์เป็นแบบเดิม สิ่งที่แก้เองจะหาย) แล้ว `git pull` ใหม่
- ตารางใหม่ในฐานข้อมูล เช่น `feedback` แอปสร้างให้เอง ไม่ต้องนำเข้าไฟล์ใหม่

### ย้ายไป XAMPP ตัวใหม่ (เช่น อัปเกรดเป็น PHP 8.3)

ติดตั้งตัวใหม่ไว้คนละโฟลเดอร์ ตัวเก่าไม่ต้องลบ ถ้ามีปัญหาก็กลับไปใช้ตัวเก่าได้

1. **สำรองฐานข้อมูลจากตัวเก่า:** phpMyAdmin → คลิก `taxeasy` ทางซ้าย → แท็บ **Export** → กด **Export** ได้ไฟล์ `taxeasy.sql`
   (ต้องคลิกชื่อฐานข้อมูลก่อน ถ้ากด Export ที่หน้ารวมจะได้ทุกฐานข้อมูล รวมถึงฐานข้อมูลระบบที่ไม่ควรย้าย)
2. ตัวเก่า: กด **Stop** ทั้ง Apache และ MySQL แล้ว **Quit**
3. ติดตั้ง XAMPP 8.3 ลงโฟลเดอร์ใหม่ เช่น `C:\xampp83` แล้วตั้งพอร์ต 8080 ตามหัวข้อด้านบน
4. Start Apache และ MySQL ของตัวใหม่
5. ติดตั้งแอปด้วย `git clone` ตามหัวข้อ "ติดตั้งแอปครั้งแรก" ข้อ 1 (เปลี่ยน `C:\xampp` เป็น `C:\xampp83`)
6. **กู้ฐานข้อมูล:** phpMyAdmin → **New** → ตั้งชื่อ `taxeasy` เลือก `utf8mb4_unicode_ci` → **Create** → แท็บ **Import** → เลือก `taxeasy.sql` → **Import**
   บัญชีแอดมิน กฎภาษี และประวัติเดิมจะกลับมาครบ
7. ถ้าเคยใส่ API key ไว้ ให้คัดลอก `server\config.local.php` จากตัวเก่ามาด้วย

ฐานข้อมูลของงานอื่นในตัวเก่ายังอยู่ครบ ถ้าต้องใช้ในตัวใหม่ ให้ Export ทีละฐานข้อมูลแบบเดียวกัน

### เปิดบนมือถือ

1. มือถือกับคอมต้องต่อ Wi-Fi วงเดียวกัน
2. ดู IP ของคอม: พิมพ์ `ipconfig` ใน Terminal แล้วดูบรรทัด **IPv4 Address** เช่น `192.168.1.20`
3. ในมือถือเปิด `http://192.168.1.20:8080/project_data/Texeasy/` (ต้องมี `:8080`)
4. ถ้าเปิดไม่ได้ ให้อนุญาต Apache ใน Windows Firewall

ปุ่ม "เพิ่มลงหน้าจอหลัก" และการใช้งานออฟไลน์ (PWA) ใช้ได้เฉพาะเมื่อเปิดผ่าน `https://` หรือ `localhost` ตามข้อกำหนดของเบราว์เซอร์ ถ้าเปิดผ่าน IP แอปยังใช้งานได้ครบ แต่ติดตั้งเป็นแอปไม่ได้

## เปิดใช้ AI ผู้ช่วย

ใช้ได้ทั้ง **น้องภาษี** (แชทถามเรื่องภาษี) และ **สแกนใบ 50 ทวิ** ต้องใช้ PHP 8.1 ขึ้นไป

1. สมัครที่ <https://platform.claude.com> เลือก **Individual**
2. เมนู **Billing** → เติมเครดิต (เริ่มที่ $5 เครดิตใช้ได้ 1 ปี) **ปิด Auto-reload** ไว้ จะได้ไม่ถูกตัดเงินเพิ่มเอง
3. เมนู **API Keys** → **Create Key** แล้วก๊อป key เก็บไว้ (เว็บโชว์ให้ดูครั้งเดียว)
4. สร้างไฟล์ `server\config.local.php` ในโฟลเดอร์แอป:
   ```php
   <?php
   $c = require __DIR__ . '/config.php';
   $c['ai']['api_key'] = 'sk-ant-...';
   $c['ai']['model'] = 'claude-haiku-5-5'; // ไม่ใส่บรรทัดนี้ = ใช้ claude-opus-5-5
   return $c;
   ```
5. เปิดหลังบ้าน หน้าแรกจะขึ้นว่า AI **เปิดใช้งาน** และบอกจำนวนข้อความกับ token ที่ใช้ใน 30 วันล่าสุด

**ห้ามส่ง API key ให้ใคร ห้ามใส่ในโค้ดฝั่งแอป หรืออัปโหลดขึ้น GitHub** ใครมี key ก็ใช้เงินในบัญชีคุณได้ (`config.local.php` อยู่ใน `.gitignore` แล้ว)

**เลือกรุ่น AI**

| รุ่น | ราคา (ต่อ 1 ล้าน token เข้า / ออก) | เหมาะกับ |
|---|---|---|
| `claude-haiku-5-5` | $0.10 / $0.50 | ทดสอบทุกวัน ถูกมาก |
| `claude-opus-5-5` (ค่าเริ่มต้น) | $4 / $20 | ตอบละเอียดที่สุด เช่น วันนำเสนอ |

แต่ละเครื่องใช้ได้ไม่เกิน 30 ครั้งต่อวัน (แชทกับสแกนรวมกัน) เปลี่ยนได้ด้วย `$c['ai']['daily_limit_per_client'] = 50;`

**ถ้าขึ้นว่า "เซิร์ฟเวอร์เชื่อมต่อ AI ไม่ได้" บน Windows:** PHP ของ XAMPP มักยังไม่ได้ตั้งไฟล์ใบรับรอง SSL

1. เปิด `C:\xampp\php\php.ini`
2. ค้น `curl.cainfo` แก้เป็น `curl.cainfo="C:\xampp\apache\bin\curl-ca-bundle.crt"`
3. ค้น `openssl.cafile` แก้เป็น `openssl.cafile="C:\xampp\apache\bin\curl-ca-bundle.crt"`
4. ลบ `;` หน้าทั้งสองบรรทัด แล้ว Stop / Start Apache ใหม่

### ข้อมูลตัวอย่างสำหรับเดโม

เปิดแอปครั้งแรก หรือกด "ใส่ข้อมูลตัวอย่าง" หน้าสรุปจะมีปุ่มสลับ 4 แบบ: มนุษย์เงินเดือน (ได้คืน), ฟรีแลนซ์ (ต้องจ่ายเพิ่ม), คนมีครอบครัว และนักลงทุน ข้อมูลตัวอย่างไม่ถูกบันทึกจนกว่าผู้ใช้จะแก้ตัวเลขหรือกด "เริ่มกรอกของฉัน" แก้หรือเพิ่มตัวอย่างได้ที่ `src/engine/examples.ts`

### ตลาดหุ้นโลก

แสดง SET, S&P 500, Nasdaq, Dow Jones, Nikkei, Hang Seng, Shanghai, FTSE, DAX, ทองคำ และค่าเงินบาท อัปเดตเองทุก 30 วินาทีขณะเปิดหน้านี้

- ข้อมูลดึงผ่าน `api/market.php` จาก Yahoo Finance (บริการฟรีที่ไม่เป็นทางการ อาจเปลี่ยนหรือหยุดได้) เก็บไว้ในตาราง `market_cache` 60 วินาที
- หุ้นไทยล่าช้าประมาณ 15 นาที ใช้ดูเท่านั้น ไม่ใช่คำแนะนำการลงทุน
- เครื่องที่รัน XAMPP ต้องต่ออินเทอร์เน็ตได้ เปลี่ยนเวลาเก็บข้อมูลได้ด้วย `$c['market'] = ['ttl' => 120];` ใน `config.local.php`

### แจ้งปัญหาและความเป็นส่วนตัว

- ผู้ใช้แจ้งได้ที่ **แท็บเพิ่มเติม → แจ้งปัญหา** หรือลิงก์ "ตัวเลขไม่ตรงกับที่ยื่นจริง? แจ้งเรา" ในหน้าสรุป เลือกแนบตัวเลขที่คำนวณไว้ได้
- ทีมดูเรื่องที่แจ้งได้ที่ **หลังบ้าน → แจ้งปัญหา** (ตัวเลขข้างเมนู = จำนวนเรื่องใหม่) กด "แก้แล้ว ปิดเรื่อง" หรือลบได้ ระบบลบเรื่องที่เก่ากว่า 1 ปีให้เอง และรับได้ไม่เกิน 10 เรื่องต่อเครื่องต่อวัน
- **นโยบายความเป็นส่วนตัว** อธิบายว่าข้อมูลอยู่ที่ไหน ส่งไปไหน และเก็บนานเท่าไร ตาม PDPA ถ้าแก้แอปให้เก็บหรือส่งข้อมูลเพิ่ม ต้องแก้ `src/screens/Privacy.tsx` และวันที่ปรับปรุงด้วย
- สถิติการใช้ AI (`chat_usage`) เก็บไว้ 90 วัน

## หลังบ้าน

### ความปลอดภัย

- **รหัสผ่าน:** อย่างน้อย 8 ตัว มีทั้งตัวอักษรและตัวเลข เปลี่ยนได้ที่เมนู "บัญชีของฉัน"
- **กันเดารหัส:** ใส่ผิด 5 ครั้งภายใน 15 นาที IP นั้นเข้าไม่ได้ 15 นาที
- **ออกจากระบบเอง** เมื่อไม่ได้ใช้งาน 2 ชั่วโมง
- **ผู้ดูแลหลายคน:** เพิ่ม/ลบได้ที่เมนู "ผู้ดูแล" (ลบบัญชีตัวเองไม่ได้ และต้องเหลืออย่างน้อย 1 คน)
- **สำรองข้อมูล:** เมนู "สำรองข้อมูล" ดาวน์โหลดไฟล์ .sql ของกฎภาษีและประวัติการทำงาน กู้คืนผ่าน phpMyAdmin → Import แนะนำให้สำรองก่อนเผยแพร่กฎใหม่
- ทุกการกระทำในหลังบ้านบันทึกไว้ในประวัติการทำงาน

### อัปเดตกฎภาษีเมื่อกฎหมายเปลี่ยน

1. เข้าหลังบ้าน แล้วกด **สร้างร่างจากฉบับนี้** ที่ฉบับที่ใช้งานอยู่
2. แก้ตัวเลขในฟอร์ม หรือเพิ่มมาตรการพิเศษในช่อง "มาตรการพิเศษรายปี" แล้วกด **บันทึกร่าง** (ระบบตรวจรูปแบบข้อมูล ถ้าผิดจะบอกว่าต้องแก้ช่องไหน)
3. ตรวจตาราง "เปลี่ยนจากฉบับที่ใช้งานอยู่" แล้วกด **เผยแพร่ให้ผู้ใช้**
4. ผู้ใช้ได้กฎใหม่เมื่อเปิดแอปครั้งถัดไป หรือเมื่อกด "ตรวจอัปเดต" ในแท็บเพิ่มเติม

ขึ้นปีภาษีใหม่ให้กด **+ สร้างปีภาษี …** ระบบคัดลอกกฎของปีล่าสุดมาเป็นร่าง เลื่อนกำหนดยื่นไป 1 ปี และล้างมาตรการพิเศษออก เพราะมาตรการเหล่านี้มักใช้ได้เฉพาะปี

ตัวอย่างมาตรการพิเศษ (ช้อปลดหย่อน):

```json
{
  "id": "easy-e-receipt-2569",
  "label": "Easy E-Receipt 2569",
  "description": "ซื้อสินค้า/บริการจากร้านที่จด VAT ระหว่าง ... ",
  "inputs": [
    { "id": "general", "label": "สินค้า/บริการทั่วไป", "multiplier": 1, "maxActual": 30000 },
    { "id": "otop", "label": "สินค้า OTOP", "multiplier": 1, "maxActual": 20000 }
  ],
  "maxDeduction": 50000
}
```

- `multiplier`: ตัวคูณ เช่น 1.5 = หักได้ 1.5 เท่าของยอดจ่าย
- `maxActual`: เพดานยอดจ่ายของแต่ละช่อง หรือของทั้งมาตรการ
- `step`: หักเป็นขั้น เช่น ทุก 1,000,000 บาท
- `maxDeduction`: ลดหย่อนสูงสุดของมาตรการ

## สำหรับนักพัฒนา (แก้โค้ดต่อ)

โค้ดต้นฉบับอยู่ในสาขา `main` ส่วนสาขา `xampp` เป็นแอปที่ build แล้ว (สร้างให้อัตโนมัติ ห้ามแก้ตรง ๆ)

ต้องมี [Node.js](https://nodejs.org) 20 ขึ้นไป และ [Composer](https://getcomposer.org) สำหรับไลบรารีฝั่ง PHP

```bash
npm install                      # ติดตั้งไลบรารีฝั่งแอป
cd public/server && composer install && cd ../..   # ไลบรารี AI ฝั่ง PHP
npm run dev                      # โหมดพัฒนา http://localhost:5173 (ใช้กฎที่ติดมากับแอป)
npm test                         # ทดสอบระบบคำนวณภาษี
npm run build                    # build ไว้ใน dist/ (GitHub ทำให้เองทุกครั้งที่ push ขึ้น main)
```

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `src/engine/` | ระบบคำนวณภาษี (`calculate.ts`) วางแผน (`plan.ts`, `optimizer.ts`) ข้อมูลตัวอย่าง (`examples.ts`) และชุดทดสอบ |
| `src/screens/` | หน้าจอ สรุป / รายได้ / ลดหย่อน / วางแผน / เพิ่มเติม / ยื่นภาษี / ตลาดหุ้น / ภ.ง.ด.94 / แจ้งปัญหา / ความเป็นส่วนตัว |
| `src/components/` | ส่วนประกอบหน้าจอ เช่น น้องภาษี (`Assistant.tsx`) สแกน 50 ทวิ (`ScanForm.tsx`) กราฟภาษี (`TaxCurve.tsx`) |
| `src/lib/` | เชื่อม API, เก็บข้อมูลในเครื่อง, ปฏิทิน, การ์ดแชร์ |
| `rules/` | กฎภาษีตั้งต้นแต่ละปี (ติดไปกับแอป และใช้สร้าง `database/seed.sql`) |
| `public/api/` | API: `rules.php` กฎภาษี · `chat.php` น้องภาษี · `scan.php` สแกน 50 ทวิ · `feedback.php` แจ้งปัญหา · `market.php` ตลาดหุ้น |
| `public/admin/` | หลังบ้าน |
| `public/server/` | ตั้งค่า เชื่อมฐานข้อมูล ตรวจรูปแบบกฎภาษี |
| `database/` | โครงสร้างฐานข้อมูล (`schema.sql`) และข้อมูลตั้งต้น (`seed.sql`) |

แก้ไฟล์ใน `rules/` แล้วรัน `npm run seed` เพื่อสร้าง `database/seed.sql` ใหม่

## ข้อจำกัดที่ควรรู้

- การเทียบยื่นรวมกับคู่สมรสเป็นการประมาณการ (เพดานเงินบริจาคคิดแยกรายคน) และยังไม่มีแบบ "แยกยื่นเฉพาะเงินเดือน"
- ภ.ง.ด.94 คิดค่าลดหย่อนและเกณฑ์วิธี 0.5% เป็นกึ่งหนึ่งของกฎทั้งปี และหักค่าใช้จ่ายแบบเหมา
- เงินได้จากต่างประเทศคิดตามคำสั่ง ป.161/2566 (ข้อเสนอยกเว้นถ้านำเข้าภายใน 2 ปี ยังไม่พบประกาศบังคับใช้)
- กฎปี 2569 ยังไม่มีมาตรการพิเศษ (ช้อปลดหย่อน เที่ยวลดหย่อน) เพราะยังไม่มีประกาศทางการ เพิ่มจากหลังบ้านได้เมื่อมีประกาศ
- แอปบอกยอดภาษี แต่ยังไม่บอกว่าผู้ใช้ "ต้องยื่นแบบหรือไม่" กรณีที่ไม่ต้องเสียภาษี
- ตัวเลขเพดานรวบรวมจากประกาศและสื่อการเงิน ณ ต.ค. 2569 ควรให้ผู้รู้เรื่องภาษีตรวจอีกครั้งก่อนเปิดให้คนทั่วไปใช้
- การสแกน 50 ทวิ ด้วย AI อาจอ่านตัวเลขผิดได้ ต้องให้ผู้ใช้ตรวจกับเอกสารจริงทุกครั้ง
- แอปเป็นเครื่องมือช่วยประมาณการภาษี ไม่ใช่คำแนะนำทางภาษีหรือการลงทุน

# ภาษีง่ายๆ (TaxEasy)

แอปคำนวณภาษีเงินได้บุคคลธรรมดาของไทย ออกแบบให้ใช้บนมือถือเป็นหลัก และใช้บนคอมได้ด้วย

- คำนวณภาษีจากรายได้ทั้ง 40(1)–40(8) (ยกเว้น 40(4)) หักค่าใช้จ่ายตามประเภท
- รู้ค่าลดหย่อนทุกหมวด พร้อมตรวจเพดานให้อัตโนมัติ เช่น กลุ่มเกษียณรวมไม่เกิน 500,000 บาท และประกันชีวิตรวมกับประกันสุขภาพไม่เกิน 100,000 บาท
- คิดภาษีทั้งวิธีขั้นบันไดและวิธี 0.5% แล้วใช้ยอดที่สูงกว่าตามกฎหมาย
- บอกว่าได้เงินคืนหรือต้องจ่ายเพิ่ม และแนะนำว่ายังลดหย่อนเพิ่มได้อีกเท่าไร จะประหยัดภาษีได้กี่บาท
- **อัปเดตกฎภาษีได้เอง:** แอดมินแก้กฎในหลังบ้านแล้วกดเผยแพร่ แอปของผู้ใช้จะดึงกฎใหม่ไปใช้ ไม่ต้องอัปเดตแอป
- **AI ผู้ช่วย "น้องภาษี":** ตอบคำถามภาษีโดยดูจากตัวเลขของผู้ใช้ (ส่งข้อมูลเมื่อผู้ใช้อนุญาตเท่านั้น)
- ข้อมูลรายได้ของผู้ใช้เก็บไว้ในเครื่องผู้ใช้ ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

## ติดตั้งบน XAMPP (ใช้ไฟล์ Texeasy.zip)

1. **แตกไฟล์** `Texeasy.zip` ไปไว้ที่ `C:\xampp\htdocs\project_data\Texeasy\`
   (ภายในต้องเห็น `index.html`, `api\`, `admin\`, `server\`, `database\`)
2. เปิด **XAMPP Control Panel** แล้วกด **Start** ที่ **Apache** และ **MySQL**
3. **สร้างฐานข้อมูล:** เปิด <http://localhost/phpmyadmin> → แท็บ **Import**
   - นำเข้า `database\schema.sql` ก่อน (ไฟล์นี้สร้างฐานข้อมูลชื่อ `taxeasy` ให้)
   - เลือกฐานข้อมูล `taxeasy` ทางซ้าย แล้วนำเข้า `database\seed.sql` (กฎภาษีปี 2568 และ 2569)
4. **สร้างบัญชีแอดมิน:** เปิด <http://localhost/project_data/Texeasy/admin/> แล้วตั้งชื่อผู้ใช้และรหัสผ่าน (ทำได้ครั้งเดียว ตอนที่ยังไม่มีบัญชี)
5. **เปิดแอป:** <http://localhost/project_data/Texeasy/>

ถ้า Apache ใน XAMPP ใช้พอร์ตอื่น (ดูช่อง Port(s) ใน XAMPP Control Panel เช่น 8080) ให้ใส่พอร์ตต่อท้าย เช่น <http://localhost:8080/project_data/Texeasy/>

**รุ่น PHP:** แอปและหลังบ้านใช้ได้กับ PHP 8.0 ขึ้นไป ส่วน AI ผู้ช่วยต้องใช้ **PHP 8.1 ขึ้นไป** ดูรุ่นได้ที่หน้าแรกของ phpMyAdmin (ช่อง Web server → PHP version) ถ้าต่ำกว่า 8.1 ให้ติดตั้ง XAMPP รุ่นใหม่ (PHP 8.2) จาก <https://www.apachefriends.org> โดยสำรองโฟลเดอร์ `htdocs` และ Export ฐานข้อมูลไว้ก่อน

ถ้า MySQL ของคุณตั้งรหัสผ่าน root ไว้ ให้แก้ในไฟล์ `server\config.php`

### อัปเดตเป็นเวอร์ชันล่าสุดด้วย git (แนะนำแทนการโหลด zip)

ทุกครั้งที่มีการแก้โค้ด GitHub จะ build แอปให้อัตโนมัติ แล้วเก็บไว้ในสาขา `xampp` ต้องติดตั้ง [Git for Windows](https://git-scm.com/download/win) ก่อน

ติดตั้งครั้งแรก (เปิด Terminal ใน VS Code):

```
cd C:\xampp\htdocs\project_data
git clone -b xampp https://github.com/chickenggeasy-cmd/taxeasy.git Texeasy
```

อัปเดตครั้งต่อไป:

```
cd C:\xampp\htdocs\project_data\Texeasy
git pull
```

ไฟล์ `server\config.local.php` (API key) ที่คุณสร้างเอง จะไม่ถูก git แตะต้อง

### เปิดบนมือถือ

- มือถือกับคอมต้องต่อ Wi-Fi วงเดียวกัน
- ดู IP ของคอม: เปิด Command Prompt พิมพ์ `ipconfig` แล้วดูบรรทัด IPv4 Address เช่น `192.168.1.20`
- ในมือถือ เปิด `http://192.168.1.20/project_data/Texeasy/`
- ถ้าเปิดไม่ได้ ให้อนุญาต Apache ใน Windows Firewall

**ปุ่ม "เพิ่มลงหน้าจอหลัก" และการใช้งานออฟไลน์ (PWA)** ต้องเปิดผ่าน `https://` หรือ `localhost` เท่านั้น เป็นข้อกำหนดของเบราว์เซอร์ ถ้าเปิดผ่าน IP ในวง Wi-Fi แอปยังใช้งานได้ครบ แต่จะติดตั้งเป็นแอปไม่ได้ ถ้านำขึ้นโฮสต์ที่มี https (ส่วนใหญ่ฟรี) ก็ติดตั้งลงมือถือได้ทันที

## เปิดใช้ AI ผู้ช่วย

1. สมัครและสร้าง API key ที่ <https://console.anthropic.com> (คิดเงินตามการใช้งาน ต้องเติมเครดิตก่อน)
2. เปิดไฟล์ `server\config.php` แล้วใส่ key แทนค่าเดิม:
   ```php
   'api_key' => 'sk-ant-...',
   ```
3. ตั้งค่าเพิ่มเติมในไฟล์เดียวกัน:
   - `model`: ค่าเริ่มต้นคือ `claude-opus-5-5` ตอบละเอียดที่สุด ถ้าต้องการประหยัดเปลี่ยนเป็น `claude-haiku-5-5` ราคาถูกกว่ามาก
   - `daily_limit_per_client`: จำนวนข้อความสูงสุดต่อเครื่องต่อวัน กันค่าใช้จ่ายบานปลาย ค่าเริ่มต้น 30
4. ดูจำนวนข้อความและ token ที่ใช้ไปได้ในหน้าแรกของหลังบ้าน

**ห้ามนำ API key ไปใส่ในโค้ดฝั่งแอป หรืออัปโหลดขึ้น GitHub แบบสาธารณะ** ถ้าจะเก็บโค้ดบน GitHub ให้สร้างไฟล์ `server\config.local.php` เก็บ key แยกไว้ (ไฟล์นี้อยู่ใน `.gitignore` แล้ว):

```php
<?php
$c = require __DIR__ . '/config.php';
$c['ai']['api_key'] = 'sk-ant-...';
return $c;
```

**ถ้าแชทขึ้นว่า "เซิร์ฟเวอร์เชื่อมต่อ AI ไม่ได้" บน XAMPP (Windows):** PHP ของ XAMPP มักยังไม่ได้ตั้งไฟล์ใบรับรอง SSL ให้แก้ดังนี้
1. เปิด `C:\xampp\php\php.ini`
2. ค้นคำว่า `curl.cainfo` แล้วแก้เป็น `curl.cainfo="C:\xampp\apache\bin\curl-ca-bundle.crt"`
3. ค้นคำว่า `openssl.cafile` แล้วแก้เป็น `openssl.cafile="C:\xampp\apache\bin\curl-ca-bundle.crt"`
4. ลบเครื่องหมาย `;` หน้าบรรทัดทั้งสอง แล้วรีสตาร์ต Apache

## อัปเดตกฎภาษีเมื่อกฎหมายเปลี่ยน

1. เข้าหลังบ้าน `admin/` แล้วกด **สร้างร่างจากฉบับนี้** ที่ฉบับที่ใช้งานอยู่
2. แก้ตัวเลขในฟอร์ม หรือเพิ่มมาตรการพิเศษในช่อง "มาตรการพิเศษรายปี" แล้วกด **บันทึกร่าง**
   - ระบบตรวจรูปแบบข้อมูลให้ ถ้าผิดจะแจ้งว่าต้องแก้ช่องไหน
3. ตรวจตาราง "เปลี่ยนจากฉบับที่ใช้งานอยู่" แล้วกด **เผยแพร่ให้ผู้ใช้**
4. ผู้ใช้จะได้กฎใหม่เมื่อเปิดแอปครั้งถัดไป หรือเมื่อกด "ตรวจอัปเดต" ในหน้าตั้งค่า

ขึ้นปีภาษีใหม่ให้กด **+ สร้างปีภาษี …** ระบบจะคัดลอกกฎของปีล่าสุดมาเป็นร่าง เลื่อนกำหนดยื่นไป 1 ปี และล้างมาตรการพิเศษออก เพราะมาตรการเหล่านี้มักใช้ได้เฉพาะปี

ตัวอย่างมาตรการพิเศษ (ช้อปลดหย่อน):

```json
{
  "id": "easy-e-receipt-2569",
  "label": "Easy E-Receipt 2569",
  "description": "ซื้อสินค้า/บริการจากร้านที่จด VAT ระหว่าง ... ",
  "inputs": [
    { "id": "general", "label": "สินค้า/บริการทั่วไป", "multiplier": 1, "maxActual": 30000 },
    { "id": "otop", "label": "สินค้า OTOP", "multiplier": 1, "maxActual": 20000 }
  ],
  "maxDeduction": 50000
}
```

- `multiplier`: ตัวคูณ เช่น 1.5 = หักได้ 1.5 เท่าของยอดจ่าย
- `maxActual`: เพดานยอดจ่ายของแต่ละช่อง หรือของทั้งมาตรการ
- `step`: หักเป็นขั้น เช่น ทุก 1,000,000 บาท
- `maxDeduction`: ลดหย่อนสูงสุดของมาตรการ

## สำหรับนักพัฒนา (แก้โค้ดต่อ)

ต้องมี [Node.js](https://nodejs.org) 20 ขึ้นไป และ [Composer](https://getcomposer.org) สำหรับไลบรารีฝั่ง PHP

```bash
npm install                      # ติดตั้งไลบรารีฝั่งแอป
cd public/server && composer install && cd ../..   # ไลบรารี AI ฝั่ง PHP (หรือคัดลอก server/vendor จาก Texeasy.zip)
npm run dev                      # เปิดโหมดพัฒนา http://localhost:5173 (ใช้กฎที่ติดมากับแอป)
npm test                         # ทดสอบระบบคำนวณภาษี
npm run build                    # สร้างไฟล์ไว้ใน dist/ แล้วคัดลอกทั้งหมดไปวางใน XAMPP
```

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `src/engine/` | ระบบคำนวณภาษี (`calculate.ts`) วางแผนภาษี (`plan.ts`) และชุดทดสอบ |
| `src/screens/` | หน้าจอ สรุป / รายได้ / ลดหย่อน / วางแผน / ตั้งค่า |
| `src/components/` | ส่วนประกอบหน้าจอ รวมถึง AI ผู้ช่วย (`Assistant.tsx`) |
| `rules/` | กฎภาษีตั้งต้นแต่ละปี (ติดไปกับแอป และใช้สร้าง `database/seed.sql`) |
| `public/api/` | API: `rules.php` (ส่งกฎภาษี) และ `chat.php` (AI ผู้ช่วย) |
| `public/admin/` | หลังบ้าน |
| `public/server/` | ตั้งค่า เชื่อมฐานข้อมูล ตรวจรูปแบบกฎภาษี |
| `database/` | โครงสร้างฐานข้อมูล (`schema.sql`) และข้อมูลตั้งต้น (`seed.sql`) |

แก้ไฟล์ใน `rules/` แล้วรัน `npm run seed` เพื่อสร้าง `database/seed.sql` ใหม่

## ข้อจำกัดที่ควรรู้

- ยังไม่รวมเงินได้ 40(4) (ดอกเบี้ย เงินปันผล) และการยื่นรวมกับคู่สมรส
- กฎปี 2569 ยังไม่มีมาตรการพิเศษ (ช้อปลดหย่อน เที่ยวลดหย่อน) เพราะยังไม่มีประกาศทางการ เพิ่มจากหลังบ้านได้เมื่อมีประกาศ
- ตัวเลขเพดานรวบรวมจากประกาศและสื่อการเงิน ณ ต.ค. 2569 ควรให้ผู้รู้เรื่องภาษีตรวจอีกครั้งก่อนเปิดให้คนทั่วไปใช้
- แอปเป็นเครื่องมือช่วยประมาณการภาษี ไม่ใช่คำแนะนำทางภาษีหรือการลงทุน
